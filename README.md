# 🔮 타로 카드

마우스 클릭 한 번으로 타로 카드를 뽑아보는 웹사이트예요.
원하는 만큼 카드를 뽑고, 카드를 원하는 자리에 직접 놓아볼 수도 있어요.

---

## ✨ 무엇을 할 수 있나요?

- **카드 뽑기** — 78장의 타로 카드 중에서 원하는 수만큼 무작위로 뽑아요.
- **카드 뜻 보기** — 뽑은 카드에 마우스를 올리면 그 카드가 가진 의미(키워드)가 나타나요.
- **정방향 / 역방향** — 카드를 똑바로만 뽑을지, 거꾸로 된 카드도 섞을지 고를 수 있어요.
- **자리 직접 배치** — '켈틱 크로스' 같은 타로 배열처럼, 카드를 놓을 자리를 직접 정할 수 있어요.

---

## 🖐️ 사용 방법

1. **카드 수**를 정해요 (예: 3장).
2. **방향**을 골라요.
   - `정방향만` : 카드가 항상 똑바로 나와요.
   - `양방향` : 거꾸로 된 카드(역방향)도 섞여 나와요.
3. **카드 뽑기** 버튼을 눌러요.
4. 나온 카드에 **마우스를 올리면** 카드의 의미가 보여요.
5. 다시 뽑고 싶으면 **다시 뽑기** 버튼을 누르면 돼요.

### 🎴 카드 자리를 직접 정하고 싶다면

`스프레드 배치`에 체크하면 카드 놓을 자리를 직접 꾸밀 수 있어요.

- **마우스로 끌어서** 번호 칸을 원하는 곳에 놓아요. (칸에 딱딱 맞춰 정렬돼요)
- 자유롭게 놓고 싶으면 `Alt` 키를 누른 채로 끌면 돼요.
- 번호 칸을 한 번 누른 뒤 **방향키(← ↑ → ↓)**로 미세하게 옮길 수도 있어요.
- 실수했다면 `Ctrl` + `Z`로 되돌리고, `Ctrl` + `Shift` + `Z`로 다시 할 수 있어요.
- `초기화`를 누르면 처음 배치로 돌아가요.

카드 수에 따라 카드 크기가 자동으로 알맞게 조절되고, 작은 카드는 마우스를 올리면 크게 확대돼서 잘 보여요.

## 💻 내 컴퓨터에서 직접 열어보려면

이 사이트는 그냥 파일을 더블클릭하면 일부 기능이 동작하지 않아요.
아래처럼 간단한 '미리보기 서버'를 띄워서 봐야 해요.

**가장 쉬운 방법 (Python이 깔려 있다면)**

1. 폴더 안에서 명령 창(터미널)을 열어요.
2. 아래 한 줄을 입력하고 엔터를 눌러요.
   ```
   python3 -m http.server 8000
   ```
3. 웹브라우저 주소창에 `http://localhost:8000` 을 입력하면 끝!

> 💡 Python이 없다면, VS Code의 'Live Server' 확장 프로그램을 쓰는 것도 아주 쉬워요.

## 🖼️ 카드 그림 출처

카드 그림은 1909년에 만들어진 **라이더-웨이트(Rider-Waite)** 타로 덱이에요.
저작권이 만료된 그림이라 누구나 자유롭게 쓸 수 있고,
[위키미디어 공용](https://commons.wikimedia.org/wiki/Category:RWS_Tarot_deck)에서 가져왔어요.
